# Projects

## Semantic search rebuild

Rebuilt platform-wide user search at Accomplishr on OpenSearch vector embeddings, dropping average response time from 5s to under 200ms at scale. The same approach was then applied to community-feed aggregation, which went from about 3s to under 200ms.

Stack: OpenSearch, vector embeddings.

## Expert recommendation engine

Production semantic-matching system at Accomplishr built on MongoDB Vector Search and OpenAI embeddings. It matches users to experts by role, skills, education and bio.

Stack: MongoDB Vector Search, OpenAI.

## Payments platform

Microservice-based payment system at Accomplishr serving every product feature that takes money. Integrates Stripe and PayPal, with identity verification built into the flow.

Stack: NestJS, Stripe, PayPal, microservices.

## RAG document summarizer

Personal project: a LangChain and OpenAI-powered summarizer supporting single and batch PDF processing.

Stack: LangChain, Python, RAG.

## Integrated Banking Loan platform

Loan-processing system managing 500,000+ public-servant records, cutting manual reconciliation by more than 60%. https://ibl.acefinancials.com.ng

Stack: Python, SQL, Next.js.

## OGFIMS

Platform built for the Ogun State Government to manage farmer enrollment, procurement and farmer-to-buyer connections. https://eshop.ogfims.org

Stack: MERN, Tailwind CSS, NestJS.

## Encrypted SMS messaging

Secure messaging system with encrypted delivery and external SMS provider integration.

Stack: Ionic, Angular, Node.js.

## Open source

- ngx-countdown: Angular directive for configurable countdown timers, with target-date binding and event hooks.
